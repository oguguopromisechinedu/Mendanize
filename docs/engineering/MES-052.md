# MES-052 — Marketplace Experience, Licensing & Revenue Control

| Field | Value |
|-------|-------|
| **Version** | 1.0 |
| **Status** | Specified |
| **Dependencies** | MES-003, MES-007, MES-021, MES-030, MES-037, MES-039, MES-040, MES-048 |
| **Surfaces** | `/account/tools-marketplace`, `/account/work`, `/account/hiring`, `/account/work/contracts/[id]`, `/dashboard/marketplace`, `/dashboard/marketplace/finance` |

## Objective

Upgrade the existing MES-039 Work + AI Tools marketplaces into a production-ready **experience** (UI + hiring workspace) and give Super Admins **configurable commissions, licensing policy, and a finance overview** — without rebuilding Stripe Connect, jobs, listings, escrow, or disputes.

This consolidates and rightsizes the pasted MES-052 / MES-053 / MES-054 / MES-055 drafts.

## What already exists (do not rebuild)

- `JobPosting`, `JobApplication`, `Contract`, `Milestone`, `ContractPayment` (escrow via Connect)
- `MarketplaceListing`, `MarketplacePurchase`, `MarketplaceSubscriptionInstance`, reviews
- Admin review queues at `/dashboard/marketplace`
- Disputes (MES-048)
- Stripe Connect rail separate from MES-021 Checkout

## In scope

### A — AI Tools Marketplace experience

- Premium catalog UI inspired by the design reference (hero, search, category chips, featured row, filters, tool cards)
- Route stays **`/account/tools-marketplace`** (learner shell; dual-auth)
- Listing detail via existing slug patterns; purchase still uses Connect
- Seller chooses **license type** at publish: Standard / Transferable / Resale-allowed
- On purchase, create a `MarketplaceLicense` row for the buyer

### B — Work Marketplace + hiring workspace

- Premium jobs UI inspired by the design reference (hero, Find Jobs / Find Talent tabs, live stats, categories, job cards)
- Route stays **`/account/work`**
- Proposals include **bid amount** + **estimated days**
- Accept hire → existing Contract + Milestone; open **`/account/work/contracts/[id]`** workspace for fund / release / chat link / milestones
- Client hiring dashboard remains `/account/hiring`

### C — Super Admin finance & commission control

- `MarketplaceCommissionRule` (TOOLS / WORK × seller tier → fee bps)
- `feeCents` resolves: active DB rule → env `STRIPE_CONNECT_PLATFORM_FEE_BPS` → default 1000 (10%)
- Super Admin page `/dashboard/marketplace/finance`: revenue overview, commission rules CRUD, escrow pending summary, license counts
- Wire into Admin Growth nav + BI cross-link

## Explicitly out of scope (dropped from pasted drafts)

- Video / voice meetings, screen share, kanban / sprint boards
- Separate App / Plugin / Template / API marketplaces
- Full tax / VAT engine, double-entry ledger, PDF/Excel report factory
- Automated resale storefront (schema supports RESALE license; UX deferred)
- Real-time presence beyond existing MES-043 messaging
- New session types or `/dashboard` access for clients/creators
- Merging Connect into MES-021 Checkout

## Acceptance criteria

1. Tools + Work marketplace pages match Mendanize design tokens and are database-driven.
2. Proposals carry bid + estimate; contract workspace funds/releases milestones.
3. Listings carry license type; purchases create licenses.
4. Super Admin can change commission bps without code deploy; finance overview aggregates Connect fees + subscription counts (reads, no second analytics stack).
5. Dual-auth boundaries unchanged.
