# Mendanize Engineering Specification (MES-003)

## Design System

**Version:** 2.0 (renumbered from original MES-002)
**Dependencies:** MES-001 (Vision), MES-002 (Shared Services), MSEM Appendix A

Follows MSEM Appendix A — Engineering Standards. No exceptions.

---

## ROLE

Principal Product Designer, Senior UI/UX Designer, Design System Architect, Senior Frontend Engineer.

---

## OBJECTIVE

Build the complete Mendanize Design System: visual language, reusable UI components, design tokens, interaction patterns every future page uses. Do NOT build homepage sections or application features.

---

## DESIGN PHILOSOPHY

Premium, modern, intelligent, educational, fast, minimal, professional. Every component reusable.

---

## DESIGN TOKENS — reads from Settings Service (MES-002)

Per MES-001's Design Customization Principle, tokens are seeded defaults stored via the Settings Service, not hardcoded. Define and seed:

Typography (Display, H1–H4, Body Large, Body, Small, Caption), Spacing Scale, Border Radius, Shadow System, Container Widths, Responsive Breakpoints, Animation Duration, Transition Timing, Z-Index Layers.

**Seeded defaults:** ink dark `#0D0D0D`, amber `#E8940C`, Bricolage Grotesque (display) + Instrument Sans (body/UI).

---

## COLOR SYSTEM

Dark-first theme: Primary, Secondary, Accent, Background, Surface, Card, Border, Text Primary/Secondary, Success, Warning, Error, Muted, Hover, Focus. Palette must support future light mode.

---

## COMPONENT LIBRARY

**Buttons:** Primary, Secondary, Outline, Ghost, Danger, Icon, Loading, Disabled/Hover/Focus states, multiple sizes.

**Forms:** Input, Textarea, Select, Checkbox, Radio, Switch, Search Input, Password Input, OTP Input, Label, Helper Text, Validation/Error/Success/Loading states.

**Cards:** Article, Category, Guide, Tool, Feature, Statistic, Empty, Loading.

**Feedback:** Toast, Alert, Badge, Progress Bar, Spinner, Skeleton, Empty/Error/Success State, Confirmation Dialog.

**Navigation:** Desktop Nav, Mobile Nav, Sidebar, Breadcrumb, Tabs, Pagination, Dropdown Menu, Context Menu.

**Overlays:** Modal, Drawer, Popover, Tooltip, Accordion, Expandable Panel.

**Layout:** Containers, Grid, Flex Utilities, Section/Content Wrapper, Responsive Columns, Spacing Utilities.

**Icons:** simple, modern, readable, consistent sizing, reusable — one icon set, not mixed sources.

---

## ANIMATION SYSTEM

Hover, Click, Fade, Slide, Scale, Loading, Page Transition. Subtle and professional — avoid excessive motion. Values (duration/timing) come from the seeded tokens, not hardcoded per component.

---

## WHAT NOT TO BUILD

Homepage, Articles, Dashboard Pages, AI Features, Authentication Pages, Business Logic, Dynamic Data.

---

## ACCEPTANCE CRITERIA

✓ Complete design token system exists, backed by the Settings Service.
✓ All reusable UI components exist, one consistent visual language.
✓ Design system ready for Homepage development (MES-005).

---

## STOP

Summarize components created, tokens established, reusability strategy. Wait for MES-004.
