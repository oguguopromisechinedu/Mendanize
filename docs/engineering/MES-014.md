# Mendanize Engineering Specification (MES-014)
## Media Library & Digital Asset Management

**Version:** 1.0
**Dependencies:** MES-002, MES-003, MES-007, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the central asset repository for Mendanize — every image, icon, and (future) video/document used platform-wide flows through here, including AI-generated assets from MES-011.

---

## BUILD
Pages: Media Library, Upload, Asset Details, Collections, Categories, Recently Uploaded, Unused Assets. Admin Dashboard Layout (MES-007).

## MEDIA LIBRARY
Grid/List view, search/filter/sort/pagination, multi-select, bulk delete/archive. Columns: thumbnail, filename, type, size, dimensions, upload date, last used, status.

## UPLOAD SYSTEM
Drag-and-drop, multi-file, progress, cancel/retry. Architecture prepared for cloud storage (Supabase Storage).

## ASSET DETAILS
Editable: Filename, Alt Text, Caption, Description, Category, Tags, Copyright, Visibility, Featured Toggle. Display: dates, usage count, dimensions, size, type.

## COLLECTIONS & CATEGORIES
Collections: Homepage, Articles, Guides, AI Tools, Branding, Marketing — create/rename/delete/move assets. Categories: Images, Logos, Icons, Documents (future), Video/Audio (future).

## MEDIA PICKER
Reusable selection component — the single implementation used by Article Editor, Guide Editor, Tool Editor, Homepage Manager, Category/Topic Editor, and AI Studio's "save to library" action. Search, filter, preview, select, replace, remove.

## DATABASE
Models: `MediaAsset, MediaCategory, MediaCollection, MediaTag, MediaUsage, AssetStatus`. One asset reusable across multiple areas.

---

## SECURITY
File type validation, upload restrictions, secure asset access, permission-based management — per Appendix A Security Baseline. No exposed file paths.

---

## WHAT NOT TO BUILD
Cloud storage integration itself (interface + schema only), image optimization service, video processing, CDN integration, automatic AI tagging.

---

## ACCEPTANCE CRITERIA
✓ Library, upload, asset details, collections, categories, and the reusable Media Picker all exist. Zero build/TS/lint errors.

---

## STOP
Summarize the DAM architecture. Explain how Articles, Guides, AI Tools, Homepage, and AI Studio reuse it. Wait for MES-015.
