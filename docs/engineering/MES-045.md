# Mendanize Engineering Specification (MES-045)

## Community Events & Learning Calendar

**Version:** 1.0 — fulfills the events system MES-036 explicitly deferred (“Upcoming learning events”).  
**Status:** Complete (MVP) — see [MES-045-COMPLETION.md](../MES-045-COMPLETION.md)  
**Dependencies:** MES-002 (Notification, Search, Media), MES-004, MES-006/MES-030, MES-007, MES-016, MES-024, MES-036, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE

Let Admins (and optionally Community Moderators) publish time-boxed learning events — workshops, AMAs, challenge kickoffs — discoverable on the Community home and a simple calendar, without building a full webinar platform.

---

## SURFACES

| Route | Purpose |
|-------|---------|
| `/community/events` | Public list + detail |
| `/community/events/[slug]` | Event page (RSVP if logged in) |
| `/dashboard/community/events` | Admin create/edit/publish |

RSVP requires `PublicUser`. Hosting Zoom/Meet links are external URLs — Mendanize does not stream video in this MES.

---

## MVP FIELDS

Title, slug, description, cover image (MES-014), start/end (timezone-aware), location type (`ONLINE` | `IN_PERSON` | `HYBRID`), external join URL, capacity (optional), status (`DRAFT` | `PUBLISHED` | `CANCELLED`).

RSVP list for Admins; reminder notifications via MES-024.

Challenges/Hackathons (MES-039) may link an `Event` optionally — do not duplicate challenge models.

---

## WHAT NOT TO BUILD

Built-in video conferencing. Ticket payments (use MES-021/039 only if a future MES requires paid events). Recurring series engine with complex RRULE UI. Multi-track conference CMS.

---

## ACCEPTANCE CRITERIA

✓ Published events appear on Community surfaces. ✓ RSVP works for authenticated learners. ✓ Reminders respect notification prefs. ✓ Moderator flag does not grant `/dashboard/*` beyond existing MES-036 rules (Admin owns create unless explicitly extended). Zero build/TS/lint errors.
