# Mendanize Engineering Specification (MES-023)
## Analytics & Insights Platform

**Version:** 1.0
**Dependencies:** MES-002, MES-007, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Give administrators meaningful data on content, learning, AI usage, and platform performance — modular, privacy-conscious, ready for future real-time reporting. This is also what turns the placeholder stats across MES-005 (Homepage), MES-007 (Dashboard Home), and MES-017 (Trending Searches) into real numbers.

---

## BUILD
Pages: Analytics Overview, Content Analytics, Learning Analytics, AI Analytics, Search Analytics, User Analytics, Traffic Analytics, Reports. Admin Dashboard Layout (MES-007).

## ANALYTICS OVERVIEW
Total Visitors, Active Users, Published Articles, Guide Views, Tool Views, Ask Mendanize AI Conversations, Search Queries, Session Duration, Returning Users, Content Engagement.

## CONTENT / LEARNING / AI / SEARCH / USER / TRAFFIC ANALYTICS
Per-domain charts and tables (top articles, guide starts, AI conversation topics, top/zero-result searches, new vs. returning users, device/browser breakdown) — each reads from a shared `AnalyticsEvent` stream rather than each module tracking its own events independently.

## REPORTS
Report list, filters, date range picker, export placeholder, scheduled reports placeholder.

## DATABASE
Models: `AnalyticsEvent, ContentAnalytics, LearningAnalytics, AIAnalytics, SearchAnalytics, TrafficAnalytics, AnalyticsReport, AnalyticsConfiguration`. `AnalyticsEvent` is the single event-capture table other modules write to (an article view, a search query, an AI message) — this is what MES-007's dashboard widgets, MES-017's Trending Searches, and MES-022's Learning Statistics will read from once wired.

---

## SECURITY
Permission-based analytics access, privacy controls, data retention policy placeholders, audit logging integration — per Appendix A.

---

## WHAT NOT TO BUILD
Real analytics tracking pipeline (event capture interface only, no production instrumentation yet), third-party analytics integration, real-time dashboards, predictive/ML insights, export functionality.

---

## ACCEPTANCE CRITERIA
✓ All analytics pages exist with placeholder-backed widgets, shared `AnalyticsEvent` schema in place. Zero build/TS/lint errors.

---

## STOP
Summarize the architecture. Explain how every module will eventually write to and read from this system. Wait for MES-024.
