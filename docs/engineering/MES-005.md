# Mendanize Engineering Specification (MES-005)
## Premium Homepage Experience

**Version:** 2.0 (renumbered from original MES-004)
**Dependencies:** MES-002, MES-003, MES-004, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build a world-class homepage communicating what Mendanize is, who it's for, why it's different. Feels like premium SaaS, not a traditional blog. All sections reusable and admin-manageable (MES-012).

---

## SECTIONS

1. **Premium Hero** — see detailed arrangement below (includes embedded Ask bar, stats strip, and **Three.js 3D brain**).
2. **Ask Mendanize AI** — public Tier 1 widget per MES-018 v2 (also embedded in Hero per reference). Interface only — real AI Service wiring is MES-018's later phase.
3. **Platform Statistics** — also shown as trust strip inside Hero; dedicated section may remain for CMS reorder. Real values from Analytics (MES-022) later.
4. **Featured This Week** — see detailed arrangement below (featured cards + **View all articles** so learners can explore all / more).
5. **Browse by Category** — see detailed arrangement below (includes **Explore all categories**).
6. **Learning Paths** — cards: cover, difficulty, duration, lessons, progress placeholder, CTA.
7. **Latest Articles** — see detailed arrangement below (list + **Load More Articles** + Stay Updated aside).
8. **Featured AI Tools** — logo, name, description, category, rating placeholder, Learn More.
9. **Why Learn With Mendanize** — 6 feature cards (reference order): AI-Powered Insights, Step-by-Step Tutorials, AI Tools & Reviews, AI Videos, Stay Updated, Community Focused. Grid: 2 cols mobile → 3 cols `sm` → 6 cols `lg`.
10. **Testimonials** — cards, prepared for future DB integration.
11. **Newsletter / Stay Updated** — lives as the aside beside Latest Articles (see below); headline, description, input, button, privacy message.
12. **FAQ** — accessible accordion.
13. **Final CTA** — strong closing section.

All section content/visibility/order is admin-manageable via MES-012 / MES-013 (Homepage CMS) — nothing hardcoded.

## PREMIUM HERO (exact arrangement)

Preserve this order and grouping. First viewport is one composition: brand signal + headline + short support + Ask/CTA group + dominant 3D visual.

### Layout
- Full-bleed section with bottom border; `overflow: hidden`.
- Background atmosphere (pointer-events none):
  - Purple radial glow (top-right / ellipse ~70% 40%)
  - Soft blue radial glow (secondary, right side)
- Content grid: **1 column** mobile; **2 equal columns** from `lg` (`grid-cols-2`, `1fr 1fr`), vertically centered.
- **Column placement is fixed — do not reverse:**
  - **Left column (`lg:col-start-1`):** copy + Ask + CTAs + stats
  - **Right column (`lg:col-start-2`):** 3D brain (desktop `lg+` only)
- Do **not** use flex/grid `order` swaps that move the brain left on desktop.
- On small screens, the 3D brain renders **between description and Ask bar** (`lg:hidden`, max-width ~300px, height ~260); the right-column brain stays `hidden lg:block`.

### Left column — content stack (top → bottom)

1. **Eyebrow pill** — Zap icon + label `Stay Ahead with AI` (bordered, soft violet fill, pill radius).
2. **Headline** — `Learn. Explore.` / line break / `Master` + accent `Ai.`  
   Display scale `clamp(30px, 5vw, 58px)`, heavy weight, tight tracking.
3. **Supporting sentence** — *Mendanize is your trusted resource for AI tools, tutorials, news, and insights to help you thrive in the age of artificial intelligence.* (muted, max-width ~430).
4. **Mobile 3D brain** — `lg:hidden` only (see 3D Brain below).
5. **Ask Mendanize AI bar** (hero-embedded):
   - Left: Bot icon in violet square
   - Placeholder text: `Ask Mendanize AI anything about AI`
   - Right: Arrow submit button
6. **Try chips** — label `Try:` then pills (in order):  
   `What is RAG?` · `How do AI agents work?` · `Claude vs GPT-4o` · `Best AI tools for developers`
7. **CTA group**
   - Primary: `Explore Latest Articles` + ArrowRight
   - Secondary (outline): `Browse All Tools`
8. **Stats / trust strip** (inline row, icon + value + label, in order):
   - Articles — `10K+`
   - AI Tools — `500+`
   - Learners — `50K+`
   - Subscribers — `100K+`
   - New Content — `Weekly`
   - Learning Hub — `AI-Powered`

### Right column — 3D Brain (desktop)

- Shown only from `lg` upward; container `min-height` ~380; canvas height ~380.
- Purple drop-shadow glow around the canvas mount.

### 3D Brain visual (Three.js) — required style

Replace flat SVG/illustration fallbacks with a **WebGL brain** matching this composition:

| Layer | Spec |
|--------|------|
| **Engine** | Three.js WebGLRenderer (`antialias`, transparent clear, DPR capped at 2) |
| **Brain mesh** | High-segment sphere with cortical fold displacement (multi-frequency sine/cos + slight top flatten); Phong material — deep violet base, emissive violet, specular highlights, ~0.93 opacity |
| **Inner core** | Smaller sphere, basic violet, low opacity glow |
| **Glow shells** | 3 back-face spheres (increasing radius, decreasing opacity) |
| **Neural net** | ~220 Fibonacci-sphere sample points on the folded surface; LineSegments for near neighbors; Points for nodes (lavender) |
| **Platform** | Horizontal rings under the brain + bright center disc + soft upward light cone/beam |
| **Lighting** | Multiple point lights (violet / blue / white) + dim ambient; intensity pulse on primary light |
| **Motion** | Continuous Y rotation; subtle X tilt + vertical float; glow/ring/center opacity pulse |
| **Floating chips** (absolute over canvas, non-interactive): Analytics · `+94% accuracy` · Generative AI · AI Agents — hide chips below ~400px width |
| **Lifecycle** | Resize handler; dispose geometries/materials/renderer and cancel rAF on unmount |
| **A11y / perf** | Decorative (`aria-hidden` or equivalent); prefer reduced-motion pause/static frame when `prefers-reduced-motion: reduce` |

CMS may still allow an optional hero image URL later; when absent, **3D brain is the default dominant visual**.

## FEATURED THIS WEEK (exact arrangement)

Preserve this order and grouping. This is the primary “hand-picked” discovery strip so learners can scan featured pieces, then **explore all / more** beyond the few cards shown.

### Header row
- Left: heading **Featured This Week**
- Right: learner escape hatch — link **View all articles** + ChevronRight  
  - Accent/link color (violet)  
  - Always visible in the header row (aligned opposite the title), same pattern as Browse by Category’s “Explore all categories”  
  - Purpose: leave the curated subset and open the full articles experience (e.g. `/articles` or CMS-configured destination)  
  - Label may be CMS-overridable later; default copy is **View all articles**  
  - Must remain a real navigational affordance — not decorative text

### Card strip
- **Mobile**: horizontal scroll row of featured cards (hide scrollbar); cards have fixed min-width so learners can swipe through.
- **Desktop (`lg+`)**: 4-column grid (no horizontal scroll); cards stretch equally.
- Each card (top → bottom):
  1. Media area — gradient/image thumb with category **badge** (top-left) and centered icon (or cover image when CMS provides one)
  2. Title
  3. Short description
  4. Meta line: `date · read time`
- Featured set is CMS-managed (MES-013 Featured content); typically a small curated count (e.g. 4) — the **View all articles** link is how learners go beyond that subset.

### Distinct from Latest Articles
| | Featured This Week | Latest Articles |
|--|--------------------|-----------------|
| Role | Curated / editor’s pick | Chronological feed |
| Escape | **View all articles** (header) | **Load More Articles** (under list) |
| Layout | Card strip / 4-up grid | List rows + Stay Updated aside |

## LATEST ARTICLES (exact arrangement)

Preserve this order and grouping.

### Layout
- Section with top border; heading **Latest Articles**.
- Content grid: **1 column** mobile; from `lg` → **`2fr` (articles) + `1fr` (Stay Updated aside)**.
- Article list inner grid: **1 column** mobile; **2 columns** from `sm`.

### Left — article list (top → bottom)

1. **Article rows** — each row is a link: colored thumb/initial tile + title + `date · read time`.
2. **Load More Articles** — placed **directly under** the article list (not under the newsletter aside).  
   - Label: `Load More Articles`  
   - Trailing ChevronDown icon  
   - Outline/ghost button style (bordered, muted text)  
   - Loads the next page/batch of latest articles (interface in MES-005; real pagination via Content/Articles services later)

### Right — Stay Updated (aside)
- Headline `Stay Updated`, short description, email input, Subscribe button, privacy line, social-proof avatars (`+50K`).
- Homepage aside may reuse the same newsletter wiring as the **global footer Newsletter** (MES-004); both are in scope.
