# Mendanize Engineering Specification (MES-011)
## Admin AI Studio (Content Generation)

**Version:** 1.0 — new module, not present in the original 25-spec draft; required by the approved reference (dashboard shows AI-generated articles, images, and video as a first-class admin capability)
**Dependencies:** MES-002 (Shared Services — multi-provider AI Service), MES-003, MES-007, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the Admin AI Studio — where administrators/editors generate article drafts, images, and video using AI, review and refine the output, and push it into the relevant content module (Articles, Media Library). This is distinct from Ask Mendanize AI (MES-019), which is learner-facing; AI Studio is an internal content-production tool.

---

## PRODUCT CONTEXT
The reference dashboard shows a Publishing Workflow: **Topic → AI Content Generation → Generate Media → SEO Optimization → Review → Schedule/Publish**. AI Studio is the engine behind the first two steps. It calls multiple providers through the AI Service (MES-002): Claude/Anthropic for article writing, DALL-E for image generation, and a video generation provider (interface prepared, provider TBD).

---

## BUILD
Pages: AI Studio Home, Generate Article, Generate Image, Generate Video, Generation History. Admin Dashboard Layout (MES-007).

## AI STUDIO HOME
Quick-start cards for each generation type, recent generations list, provider status (reuses the AI & API Status panel from MES-007).

## GENERATE ARTICLE
Input: Topic, target Category/Topic, tone/style guidance, target length. Output: draft article body, streamed, editable inline, with a "Send to Article Editor" action that hands off into MES-008's editor pre-filled.

## GENERATE IMAGE
Input: prompt, style guidance, aspect ratio. Output: image grid, select-and-save into Media Library (MES-014) via the Media Service (MES-002).

## GENERATE VIDEO
Input: prompt, duration, style. Interface and architecture only in this phase — provider wiring deferred until a video provider is selected.

## GENERATION HISTORY
Log of past generations: type, prompt, provider used, output, linked content (which Article/Media asset it became), timestamp. Supports search/filter.

## DATABASE
Models: `AIGeneration, AIGenerationType, AIGenerationProvider`. Links optionally to `Article.id` or `MediaAsset.id` once a generation is accepted into those modules.

---

## WHAT NOT TO BUILD
Video provider integration (interface only), automated end-to-end publishing without human review, fine-tuning/custom models, batch generation queues.

---

## ACCEPTANCE CRITERIA
✓ AI Studio Home, Generate Article/Image/Video interfaces, Generation History, and the hand-off into Article Editor and Media Library all exist. Zero build/TS/lint errors.

---

## STOP
Summarize the AI Studio architecture. Explain how it hands off into Article Management and Media Library, and how it relates to (but is distinct from) Ask Mendanize AI. Wait for MES-012.
