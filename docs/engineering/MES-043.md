# Mendanize Engineering Specification (MES-043)

## Learner Messaging (Direct Messages)

**Version:** 1.0 — reopens messaging deliberately deferred by MES-036 and MES-039.  
**Status:** Complete (MVP) — see [MES-043-COMPLETION.md](../MES-043-COMPLETION.md)  
**Dependencies:** MES-002 (Notification, Media, Audit), MES-006/MES-030, MES-007 (moderation reports), MES-024, MES-036 (Community), MES-039 (optional job-context threads), MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE

Give authenticated learners private 1:1 (and small-group) messaging so Community and marketplace conversations are not forced into public discussions — without building a full Slack clone.

---

## ARCHITECTURAL PLACEMENT

- Surfaces under `/account/messages` (and optional deep links from `/community` profiles / job applications).  
- Requires `PublicUser` session. Never grants `/dashboard/*`.  
- Admin moderation: report queue only — Admins do not “log in as” participants.

---

## MVP CAPABILITIES

- Start a thread with another `PublicUser` (block list respected).  
- Send text messages; optional image attachments via Media Library (MES-014).  
- Read receipts (simple `lastReadAt`), not typing indicators in v1.  
- Mute thread; report message → Admin review.  
- Notifications via MES-024 (in-app + email per prefs).

Optional context attachment: `JobApplication` or `Contract` id (MES-039) for hiring threads — same messaging models, not a second chat system.

---

## DATA MODEL (MVP)

`MessageThread`, `MessageThreadParticipant`, `Message`, `MessageReport` — all `publicUserId`-scoped. Soft-delete for sender recall within a short window.

---

## WHAT NOT TO BUILD

Real-time WebSocket infrastructure as a hard requirement (polling or SSE is acceptable for MVP). Team channels with roles that collide with platform `Admin`. Voice/video calling. Employer-only chat products. End-to-end encryption theater.

---

## ACCEPTANCE CRITERIA

✓ Two learners can exchange DMs. ✓ Reports reach Admin moderation. ✓ No Admin impersonation path. ✓ Notifications respect preferences. Zero build/TS/lint errors.

---

## STOP

Confirm dual-auth boundary. Wait for approval before real-time presence features.
