# Mendanize Engineering Specification (MES-008)
## Article Management System (CMS)

**Version:** 1.0
**Dependencies:** MES-002 (Shared Services), MES-003 (Design System), MES-007 (Admin Dashboard), MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the professional Article Management System — the primary content engine of Mendanize, powering the Learn pillar. Administrators and Editors create, edit, organize, publish, schedule, and manage educational articles. Visitors cannot publish. Scalable to tens of thousands of articles.

---

## BUILD
Pages: All Articles, Create Article, Edit Article, Preview Article, Drafts, Scheduled, Published, Archived. All use the Admin Dashboard Layout (MES-007).

## ARTICLE LIST
Professional data table via the Content Service (MES-002): search, filter, sort, pagination, bulk select/delete/publish/archive. Columns: status badge, category, author, publish date, last updated, featured indicator, reading time, actions.

## ARTICLE EDITOR
Fields: Title, Slug, Featured Image, Short Description, Main Content, Category, Topic, Tags, SEO fields (Title, Description, Focus Keyword, Canonical URL, Social Image — via the SEO Service, MES-002), Publish Status/Date, Featured Toggle, Reading Time (auto-estimated), Author. Actions: Save Draft, Preview, Publish, Archive.

## RICH TEXT EDITOR
Headings, paragraphs, lists, quotes, code blocks, images, videos, tables, callout boxes, internal/external links, horizontal rules.

## AI-ASSISTED AUTHORING
Editor includes an "Generate with AI" entry point calling the AI Service (MES-002) — draft generation, rewriting, and summarization assist. This is the Article module's integration point with the Admin AI Studio (MES-011); the AI Studio itself is a separate, dedicated spec — this module just consumes it.

## ARTICLE WORKFLOW
States: Draft, Review, Scheduled, Published, Archived. Architecture prepared for future approval workflows.

## MEDIA SELECTION
Placeholder interface for Featured/Inline Images and Video Embeds — real implementation is the Media Picker (MES-013), reused here via the Media Service (MES-002).

## ARTICLE PREVIEW
Responsive preview showing how the article renders on the public site (MES-024).

## DATABASE
Models: `Article, ArticleStatus, Tag, ArticleTag, ArticleRevision, FeaturedImage`. Article references CategoryId/TopicId per the shared taxonomy (MES-009). No version history yet.

---

## WHAT NOT TO BUILD
Media Library functionality itself, live AI generation logic (only the entry point), real analytics, public article pages (MES-024).

---

## ACCEPTANCE CRITERIA
✓ List, Create/Edit, rich text editor, SEO panel, preview, workflow states, AI entry point all exist and work. Zero build/TS/lint errors.

---

## STOP
Summarize the architecture. Explain how Categories/Topics, Media Library, SEO, AI Studio, and the public site integrate. Wait for MES-009.
