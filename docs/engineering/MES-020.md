# Mendanize Engineering Specification (MES-020)
## Platform Settings & Configuration System

**Version:** 1.0
**Dependencies:** MES-002 (Shared Services — Settings Service), MES-003, MES-007, MES-011 (AI Studio), MES-019 (Ask Mendanize AI), MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the centralized Platform Settings system controlling the entire Mendanize ecosystem from one location — General, Branding, Localization, Authentication, AI, Search, Email, Security, Maintenance, Feature Flags. **This module is the single canonical owner of AI configuration** — MES-011 (AI Studio) and MES-019 (Ask Mendanize AI) both link here rather than each defining their own AI settings screen.

---

## BUILD
Pages: Settings Dashboard, General, Branding, Localization, Authentication Settings, AI Settings, Search Settings, Email Settings, Security Settings, Maintenance Mode, Feature Flags, Backup & Restore (placeholder). Admin Dashboard Layout (MES-007).

## SETTINGS DASHBOARD
Overview cards: Platform Status, Version, Active Features, Auth/AI/Search/Email/Maintenance status, Last Updated.

## GENERAL
Platform Name/Description, Website URL, Contact/Support Email, Time Zone, Date Format, Language, Default Homepage, Default User Role.

## BRANDING
Reads from / writes to the Design Customization system's Brand Manager (per MES-003's Design Customization Principle) — this screen is the settings entry point, not a duplicate store.

## LOCALIZATION
Default Language, Available Languages (placeholder), Time Zone, Date/Number Format, Currency placeholder — prepares for future multilingual support without building it.

## AUTHENTICATION SETTINGS
Registration Enabled, Email Verification, Password Policy placeholder, Session Timeout placeholder, Remember Me, 2FA placeholder — configuration surface over MES-006's auth system, not a reimplementation.

## AI SETTINGS (canonical, single location)
Default AI Provider per capability (writing → Claude, images → DALL-E, etc.), Maximum Response Length, Conversation History Toggle (Ask Mendanize AI), Prompt Template management, Rate Limit placeholder. MES-011's AI Studio and MES-019's Ask Mendanize AI dashboard both read this — neither defines its own copy.

## SEARCH / EMAIL / SECURITY SETTINGS
Search: enabled, suggestions, trending, result limit. Email: sender name/email, SMTP placeholder, template management placeholder. Security: login attempt limits, audit logging toggle, API access placeholder — per Appendix A Security Baseline.

## MAINTENANCE MODE
Enable toggle, message, allowed admins, banner.

## FEATURE FLAGS
Enable/disable modules: Articles, Guides, AI Tools, Ask Mendanize AI, Search, Analytics, Notifications, future modules.

## DATABASE
Models: `PlatformSetting, BrandingSetting, LocalizationSetting, AuthenticationSetting, AIPlatformSetting, SearchPlatformSetting, EmailSetting, SecuritySetting, FeatureFlag, MaintenanceConfiguration`.

---

## WHAT NOT TO BUILD
Real SMTP configuration, real backups, cloud integrations, environment variable editing.

---

## ACCEPTANCE CRITERIA
✓ Settings Dashboard and all sub-modules exist, AI Settings confirmed as the single source both MES-011 and MES-019 reference. Zero build/TS/lint errors.

---

## STOP
Summarize the architecture. Confirm which other modules read from this system rather than duplicating settings. Wait for MES-021.
