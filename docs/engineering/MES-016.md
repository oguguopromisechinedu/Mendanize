# Mendanize Engineering Specification (MES-016)
## Navigation & Menu Management (Navbar Manager)

**Version:** 1.0
**Dependencies:** MES-002, MES-003, MES-004, MES-007, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the centralized system managing every navigation element platform-wide — Main Navigation, Mobile Navigation, Footer, Quick Links, Utility Navigation, Legal Links, Social Links — with zero code changes required.

---

## BUILD
Pages: Navigation Overview, Main/Mobile/Footer Navigation Builder, Quick Links, Utility Navigation, Legal Links, Social Links. Admin Dashboard Layout (MES-007).

## MENU BUILDER
One reusable component shared across Main, Mobile, and Footer navigation. Add item, nested sub-items (multi-level), drag-and-drop reorder with keyboard fallback, rename/delete. Item types: Internal Page, Article, Category, Topic, Guide, AI Tool, Custom External URL — extensible to future content types without redesigning the builder. Icon selection, open-in-new-tab toggle, visibility toggle, highlight/badge label.

## MAIN / MOBILE / FOOTER NAVIGATION
Main: primary items, dropdown-ready nesting, active-state rules, max depth. Mobile: independently structured from desktop, collapsible groups. Footer: multiple columns, column titles/reordering, newsletter placeholder reference (MES-013), copyright text.

## QUICK LINKS / UTILITY / LEGAL / SOCIAL
Lightweight lists: label, destination, icon, order, visibility. Social links auto-map icons by platform.

## MENU LOCATIONS
Maps a built menu structure to a placement (Main/Mobile/Footer Column/Utility Bar) — one menu, reusable/reassignable across locations without rebuilding.

## DATABASE
Models: `NavigationMenu, MenuItem (self-referencing for nesting), MenuItemType, MenuLocation, SocialLink, LegalLink`.

---

## THE HANDOFF
This replaces the hardcoded navigation placeholders from MES-004 — the Public Layout's header/footer read from this system, not from code.

---

## ACCEPTANCE CRITERIA
✓ Menu Builder (reusable across all three nav types), Quick Links, Utility, Legal, Social management, and Menu Locations all exist. Zero build/TS/lint errors.

---

## STOP
Summarize the architecture and confirm it replaces MES-004's hardcoded placeholders. Wait for MES-017.
