# Mendanize Engineering Specification (MES-027)
## Public AI Tools Directory

**Version:** 1.0
**Dependencies:** MES-002, MES-004, MES-012, MES-015, MES-018, MES-019, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the public AI Tools discovery experience — educational, not a bare software listing — helping users discover, evaluate, and learn about AI tools while staying connected to Articles, Guides, and Ask Mendanize AI.

---

## BUILD
AI Tools Directory, Tool Details Page, Categories, Filters, Search, Comparison placeholder, Related Learning Resources. Public Website Layout (MES-004).

## DIRECTORY
Grid/List view, search bar, advanced filters, sort, pagination, featured tools. Cards: logo, name, description, pricing, category, topic, featured badge, difficulty.

## FILTERS
Category, Topic, Pricing, Platform, Difficulty, Featured, Recently Added, Alphabetical.

## TOOL DETAILS
Logo, cover, name, developer, website, descriptions, pricing, platforms, use cases, features, advantages/limitations, difficulty, recommended audience.

## LEARNING PANEL
What You'll Learn, When To Use This Tool, Best Use Cases, Learning Outcomes, Beginner Tips.

## RELATED RESOURCES
Related Articles/Guides/Categories/Topics, Similar Tools — via Recommendations Service (MES-018).

## ASK MENDANIZE AI
Tier 1 public widget (MES-019): "Explain This Tool," "Compare Similar Tools," "Recommend Alternatives."

## COMPARISON
Placeholder interface (Compare Features/Pricing/Difficulty/Use Cases) — no comparison logic yet.

## SEO
Full Appendix A SEO Standard, Product/SoftwareApplication structured data via SEO Service (MES-015).

---

## WHAT NOT TO BUILD
User reviews, ratings, bookmarks, real comparison engine, affiliate tracking (future, tied to MES-001 Business Objectives).

---

## ACCEPTANCE CRITERIA
✓ Directory, Tool Details, Filters, Search, Learning Panel, Ask Mendanize AI, Related Resources, Comparison placeholder, SEO all exist. Zero build/TS/lint errors.

---

## STOP
Summarize the architecture. Explain integration with Articles, Guides, Categories, Search, SEO, Analytics, User Learning, Ask Mendanize AI. Wait for MES-028.
