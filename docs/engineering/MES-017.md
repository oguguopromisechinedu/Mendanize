# Mendanize Engineering Specification (MES-017)
## Search & Discovery Engine

**Version:** 1.0
**Dependencies:** MES-002 (Shared Services — Search Service), MES-003, MES-004, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the unified search system across Articles, Guides, AI Tools, Categories, Topics — one architecture, not per-module search logic.

---

## BUILD
Global Search (reusable component, embedded in header per MES-004), Search Results Page, Search Filters, Search Suggestions, Recent/Trending Searches, Empty/No-Results states, Search Settings (dashboard).

## GLOBAL SEARCH
Large input, keyboard shortcut placeholder, voice search placeholder, clear button, loading state, live suggestions.

## SEARCH RESULTS
Grouped by content type (Article/Guide/Tool/Category/Topic), each result showing title, description, type, thumbnail, category, reading time/difficulty where applicable, date.

## FILTERS
Content Type, Category, Topic, Difficulty, Publish Date, Featured, Recently Updated — reusable filter components (MES-003).

## SUGGESTIONS / RECENT / TRENDING
Placeholder-backed initially; Trending later reads real view counts once Analytics (MES-023) lands. Recommendations-adjacent suggestions call the Recommendations Service (MES-018) rather than inventing separate logic.

## SEARCH SETTINGS (dashboard)
Configuration, ranking rules, synonyms/stop-words placeholders, search analytics placeholder.

## IMPLEMENTATION NOTE
Postgres full-text search (`tsvector`) via Supabase is sufficient for this phase — no dedicated search service needed yet.

## DATABASE
Models: `SearchConfiguration, SearchHistory, TrendingSearch, SearchSuggestion, SearchFilter`.

---

## WHAT NOT TO BUILD
Real semantic/AI search, real search analytics, personalized ranking, voice search backend, autocomplete backend.

---

## ACCEPTANCE CRITERIA
✓ Global Search, Results, Filters, Suggestions, Recent/Trending, Settings all exist. Zero build/TS/lint errors.

---

## STOP
Summarize the architecture. Explain integration with all content modules, Homepage, Navigation, and Ask Mendanize AI. Wait for MES-018.
