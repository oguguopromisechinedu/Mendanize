# Mendanize Engineering Specification (MES-010)
## Learning Guides Management

**Version:** 1.0
**Dependencies:** MES-002, MES-003, MES-007, MES-009, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the management system for Learning Guides — structured, multi-lesson educational experiences (distinct from single-page Articles), serving the Learn and Practice pillars. Scalable to thousands of guides.

---

## PRODUCT CONTEXT
Each Guide belongs to a Topic (MES-009). A Guide contains Sections; Sections contain Lessons. Lessons may reference Articles, AI Tools, videos, code examples (future: quizzes). Architecture must support this expansion without redesign.

---

## BUILD
Pages: All Guides, Create/Edit Guide, Preview, Drafts/Published/Archived. Admin Dashboard Layout (MES-007).

## GUIDE LIST
Search/filter/sort/pagination/bulk actions. Columns: cover, title, category, topic, difficulty, duration, section/lesson counts, status, author, updated.

## GUIDE EDITOR
Title, Slug, Cover Image, Short/Full Description, Category, Topic, Difficulty Level, Estimated Completion Time, Learning Objectives, Prerequisites, Featured Toggle, Publish Status/Date, SEO fields.

## GUIDE STRUCTURE BUILDER
Visual builder: add/rename/reorder/delete Sections; add/reorder/delete Lessons within a Section. Drag-and-drop with keyboard-operable fallback (per Appendix A accessibility standard).

## LESSON MANAGEMENT
Title, Slug, Rich Text Content, Reading Time, Featured Image, Video/Code Example/Resource Link placeholders.

## GUIDE PREVIEW
Responsive preview: cover, title, description, difficulty, duration, objectives, sections/lessons, progress placeholder.

## DATABASE
Models: `Guide, GuideSection, GuideLesson, GuideStatus, GuideDifficulty, GuideRevision`. `GuideProgress` modeled but not implemented — real progress tracking is a future spec once user accounts/personalization (MES-021) are live, tracked in the Future Roadmap.

---

## WHAT NOT TO BUILD
Student progress tracking, quizzes, certificates, public guide pages (MES-025), AI recommendations, comments, ratings.

---

## ACCEPTANCE CRITERIA
✓ Guide management, editor, structure builder, lesson management, preview, database models all exist. Zero build/TS/lint errors.

---

## STOP
Summarize the architecture. Explain integration with Categories/Topics, Articles, AI Tools, future progress tracking, and Ask Mendanize AI. Wait for MES-011.
