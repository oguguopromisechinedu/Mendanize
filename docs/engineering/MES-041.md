# Mendanize Engineering Specification (MES-041)

## Public Static Pages CMS (Company Pages)

**Version:** 1.0  
**Status:** Specified  
**Dependencies:** MES-002 (Shared Services), MES-004 (Public Website Structure — routes already exist), MES-007 (Admin Dashboard — Pages domain), MES-014 (Media Library — featured images), MES-015 (SEO Center — metadata fields), MES-016 (Navigation — footer/nav links point at `/{slug}`), MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE

Make the Dashboard **Pages** module the single source of truth for static company/marketing pages. Remove hard-coded placeholder copy on public routes. If a page is missing or unpublished, show a real 404 — not placeholder text.

---

## SCOPE

Published `StaticPage` records render at `/{slug}` for company routes including (at minimum):

`/about`, `/contact`, `/privacy`, `/terms`, `/cookies`, `/faq`, `/careers`, `/partners`

Optional CMS takeover for `/pricing` when a published page with slug `pricing` exists; otherwise the billing catalog UI (MES-021) remains. **`/community` is not a static page** — it remains MES-036's Community Platform.

---

## ADMIN EDITOR (required fields)

- Page title  
- URL slug  
- Hero (optional eyebrow/line)  
- Rich text content  
- Excerpt (subtitle / SEO fallback)  
- Featured image + alt (via Media Library, MES-014)  
- SEO title, meta description  
- Status: Draft / Review / Published / Archived  
- Save draft, Publish, Unpublish, Preview  

---

## PUBLIC RENDER

For a published page: title, hero (if set), featured image (if set), rich content, SEO metadata. Unpublished or missing → `notFound()`. Publish must revalidate `/{slug}` so the live site updates immediately.

---

## WHAT NOT TO BUILD

A second CMS parallel to Articles. Page versioning/history. Multi-locale page variants (see future i18n if ever scoped). Turning `/community` or other product apps into CMS documents.

---

## ACCEPTANCE CRITERIA

1. Creating/editing Contact in Dashboard → Pages and publishing shows that content at `/contact` immediately.  
2. Same behavior for every listed company route.  
3. Draft/unpublished pages are not publicly reachable.  
4. Footer/nav links keep working without code changes when they already point at `/{slug}`.  
5. Zero build/TS/lint errors.

---

## STOP

Summarize completion. Confirm dual-auth: only `Admin` editors mutate pages; public routes are read-only. Wait for next spec.
