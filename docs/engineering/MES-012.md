# Mendanize Engineering Specification (MES-012)
## AI Tools Management

**Version:** 1.0
**Dependencies:** MES-002, MES-003, MES-007, MES-009, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the management system for the AI Tools directory — the primary Discover-pillar module. Every tool is an educational resource, connected to Articles, Guides, Categories, Topics, and future recommendations — not a bare listing.

---

## BUILD
Pages: All Tools, Add/Edit Tool, Preview, Draft/Published/Archived. Admin Dashboard Layout (MES-007).

## TOOLS TABLE
Search/advanced filters/sort/pagination/bulk actions. Columns: logo, name, slug, category, topic, developer, pricing model, status, featured, updated.

## TOOL EDITOR
**Basic:** Name, Slug, Short/Full Description, Logo, Cover Image, Website, Developer.
**Classification:** Category, Topic, Tags, Platform, Availability.
**Pricing:** Free / Freemium / Paid / Enterprise.
**Features:** Feature List, Use Cases, Advantages, Limitations.
**Educational:** Difficulty Level, Recommended For, Learning Outcomes, Related Articles/Guides/Tools (via Recommendations Service once MES-018 lands; manual override always available).
**Media:** Screenshots, Demo Video placeholder.
**SEO:** via SEO Service (MES-002).
**Publishing:** Featured Toggle, Status, Date.

## TOOL PREVIEW
Responsive preview matching the public AI Tool page (MES-027).

## DATABASE
Models: `Tool, ToolCategoryRelation, ToolTopicRelation, ToolPricing, ToolFeature, ToolStatus, ToolImage, ToolTag`. Curated by admins — no user submissions in this phase.

---

## WHAT NOT TO BUILD
User reviews, ratings, bookmarks, comparison engine, public directory (MES-027), Ask Mendanize AI integration (its own spec).

---

## ACCEPTANCE CRITERIA
✓ Tools management, editor, preview, database models all exist. Zero build/TS/lint errors.

---

## STOP
Summarize the architecture. Explain integration with Articles, Guides, Categories, Topics, Search, Homepage, and Ask Mendanize AI. Wait for MES-013.
