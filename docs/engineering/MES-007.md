# Mendanize Engineering Specification (MES-007)
## Admin Dashboard Foundation

**Version:** 2.0 (renumbered from original MES-006; sidebar and dashboard-home widgets enriched to match the approved reference — see Visual Reference note)
**Dependencies:** MES-002, MES-003, MES-006, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## VISUAL REFERENCE
The approved reference shows a dashboard significantly richer than a bare shell: real widget content, an AI Studio, and a fuller nav. Use it for structure and information architecture — not literal color (reference uses purple/dark-navy, which is the flagged old direction; Mendanize uses the locked ink/amber palette from MES-003).

---

## OBJECTIVE
Build the reusable Admin Dashboard framework — layout, navigation, and dashboard-home widget *shells* — that every future management module (Articles, Categories, AI Tools, etc.) plugs into. This phase builds the framework and widget shells with placeholder data; it does not implement the underlying features those widgets summarize.

---

## BUILD
Admin Dashboard Layout: Collapsible Sidebar, Top Navigation Bar, Main Content Area, Breadcrumb, Notification Area (placeholder), User Profile Menu, Theme Toggle (placeholder), Quick Search / "Ask Mendanize AI anything" command bar (placeholder, ties into MES-018's AI Service later).

## SIDEBAR NAVIGATION
Structure, grouped:

**Main:** Dashboard, AI Studio, Articles, Categories, Topics, Learning Guides, Navbar Manager, Media Library, Pages, Comments

**Content & SEO:** Tags, SEO Center, Redirects, Sitemap, Broken Links

**Growth & Engagement:** Newsletter, Subscribers, Analytics

**Users & Management:** Users & Roles, Workflow, Activity Log

**System:** AI & Integrations, Automation, Knowledge Base, Settings

Support: active states, icons, nested/collapsible groups, mobile responsiveness, future permission-based visibility. Do not hardcode business logic — nav items pull from the Navigation Service (MES-015) same as public nav.

## TOP NAVIGATION
Global Search, Notifications, User Avatar/Menu, Breadcrumb, Quick Actions — interface only.

## DASHBOARD HOME
Widget shells (placeholder data, wired to real data as each source module lands):

- **Stat cards:** Articles, Images, Videos, Learning Guides, Total Visitors, Domain Authority
- **Quick Access grid:** Create Article, Create Guide, Add Category, Add Topic, Upload Media, Create Page
- **Recent Activity** feed
- **Recent Articles** table (title, status, author, SEO score, views, date)
- **Content Overview** donut chart (breakdown by content type)
- **Top Categories** ranked list
- **Analytics Overview** mini-charts: Visitors, Page Views, Avg Read Time, Bounce Rate, SEO Score, New Subscribers
- **Publishing Workflow** panel — visualizes the content pipeline: Topic → AI Content Generation → Generate Media → SEO Optimization → Review → Schedule/Publish
- **AI & API Status** panel — per-provider connection status (Claude/Anthropic, OpenAI, Gemini, Grok, DALL-E) per the multi-provider AI Service (MES-002)
- **System Overview** — storage usage, bandwidth usage, AI credits remaining (placeholders until Billing/MES-020 and real usage tracking land)

## REUSABLE DASHBOARD COMPONENTS
Statistic Cards, Data Tables, Empty/Loading States, Page Header, Action Toolbar, Filter Bar, Search Bar, Confirmation Dialog, Status Badge, Pagination, Tabs, Drawer, Side Panel — all per MES-003.

Super Admin, Admin, Editor — architecture only, no permission enforcement yet.

---

## WHAT NOT TO BUILD
Article/Category/Topic/Guide/AI Tool management logic, media uploads, real analytics, real SEO functionality, homepage editing, user management logic, AI Studio's actual generation logic (own future spec).

---

## ACCEPTANCE CRITERIA
✓ Dashboard Layout, responsive sidebar (matching the grouped structure above), top nav, dashboard home with all widget shells, placeholder routes, reusable components — all exist and follow MES-003.

---

## STOP
Summarize the dashboard architecture. Explain how future modules (Articles, AI Studio, SEO Center, Analytics, etc.) plug into each corresponding widget/nav item. Wait for MES-008.
