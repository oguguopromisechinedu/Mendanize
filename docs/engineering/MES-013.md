# Mendanize Engineering Specification (MES-013)
## Homepage Content Management System

**Version:** 1.0
**Dependencies:** MES-002, MES-003, MES-005, MES-007, MES-009, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Make every homepage section (built in MES-005) fully admin-manageable — enable/disable, reorder, feature specific content — with zero code changes required, per MES-001's Design Customization Principle.

---

## BUILD
Pages: Homepage Overview, Section Management, Hero Management, Featured Categories/Articles/Guides/Tools, Statistics Management, Testimonials, FAQ Management, Newsletter Section, Final CTA Management. Admin Dashboard Layout (MES-007).

## HOMEPAGE OVERVIEW
Status, last updated, active/hidden sections, featured content summary, preview button, publish button.

## SECTION MANAGEMENT
Per section: Enable/Disable, drag-and-drop reorder (keyboard fallback per Appendix A), visibility rules, background style, animation toggle, spacing.

## HERO MANAGEMENT
Headline, Supporting Text, Primary/Secondary CTA, Hero Image, Background Gradient, Trust Indicators, Ask Mendanize AI placeholder text (ties into MES-019's public widget copy).

## FEATURED CONTENT MANAGERS
Categories/Articles/Guides/Tools: manual selection (with automatic-selection placeholder for future), display limit, sort order, section title — pulling from the Content Service (MES-002).

## STATISTICS MANAGEMENT
Manual values now (Articles, Guides, Tools, Categories, etc.); prepared for automatic calculation once Analytics (MES-023) is live.

## FAQ / NEWSLETTER / FINAL CTA
Standard content editors per the field lists established in MES-005's sections.

## DATABASE
Models: `Homepage, HomepageSection, HomepageHero, HomepageStatistic, HomepageFAQ, HomepageCTA, HomepageFeaturedContent`.

---

## WHAT NOT TO BUILD
Live preview synchronization, version history, A/B testing, real analytics-driven statistics.

---

## ACCEPTANCE CRITERIA
✓ Every homepage section is manageable, reorderable, database-backed. Zero build/TS/lint errors.

---

## STOP
Summarize the architecture. Explain integration with Articles, Categories, Guides, Tools, Navigation, and future personalization. Wait for MES-014.
