# Mendanize Engineering Specification (MES-015)
## SEO & Metadata Management (SEO Center)

**Version:** 1.0
**Dependencies:** MES-002, MES-003, MES-007, MSEM Appendix A

Follows MSEM Appendix A — including its SEO Standard, which this module implements the tooling for. No exceptions.

---

## OBJECTIVE
Build the centralized SEO Center enabling admins to optimize every public page — Homepage, Articles, Categories, Topics, Guides, AI Tools, static pages — through one reusable architecture new content types can adopt without modification.

---

## BUILD
Pages: SEO Dashboard, Global SEO Settings, Metadata Templates, Sitemap Management, Robots.txt Management, Redirect Management, Structured Data Management. Admin Dashboard Layout (MES-007).

## SEO DASHBOARD
Placeholder widgets: Indexed Pages, Pages Missing Metadata, Duplicate Titles/Descriptions, Missing Images, Redirect Summary, Sitemap/Structured Data status.

## GLOBAL SEO SETTINGS
Website Title, Default Meta Title/Description, Default OG/Twitter Image, Brand Name, Site Language, Canonical Domain, Default Robots Rules, Favicon, Apple Touch Icon.

## METADATA MANAGEMENT (per content type, via SEO Service)
SEO Title, Meta Description, Focus Keyword, Canonical URL, Slug, OG Title/Description/Image, Twitter Title/Description/Image, Robots Index/Follow. Built as reusable components every content editor (Article, Guide, Tool, Category) consumes — this is why MES-008/010/012 all say "via the SEO Service" instead of building their own SEO panel.

## METADATA TEMPLATES
Default templates per content type with placeholder variables: `{title}`, `{category}`, `{topic}`, `{brand}`, `{year}`.

## SITEMAP / ROBOTS / REDIRECTS / STRUCTURED DATA
Management interfaces per content type — status view, include/exclude rules, manual regeneration placeholder (real generation deferred), redirect table (source/destination/type/status), structured data schema previews (Organization, Website, Article, Guide, AI Tool, Breadcrumb).

## DATABASE
Models: `SEOProfile, MetadataTemplate, Redirect, StructuredData, RobotsRule, SitemapConfiguration, GlobalSEOSettings`.

---

## WHAT NOT TO BUILD
Real SEO scoring, real sitemap generation, real indexing, automatic keyword suggestions, Search Console integration, analytics integration.

---

## ACCEPTANCE CRITERIA
✓ SEO Dashboard, Global Settings, Metadata Templates, Sitemap/Robots/Redirect/Structured Data interfaces all exist. Zero build/TS/lint errors.

---

## STOP
Summarize the SEO architecture. Explain how every content type shares it. Wait for MES-016.
