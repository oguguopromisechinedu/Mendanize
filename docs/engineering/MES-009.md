# Mendanize Engineering Specification (MES-009)
## Categories & Topics Management

**Version:** 1.0
**Dependencies:** MES-002, MES-003, MES-007, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the taxonomy system every content module depends on. Categories are the top level (e.g. Artificial Intelligence, Programming); Topics belong to one Category (e.g. Machine Learning, Prompt Engineering); Articles, Guides, and AI Tools all attach to Topics. Scalable to thousands of entries.

---

## BUILD
Pages: All Categories, Create/Edit Category, Category Details; All Topics, Create/Edit Topic, Topic Details. Admin Dashboard Layout (MES-007).

## CATEGORY LIST/EDITOR
List: search/filter/sort/pagination/bulk actions; columns for image, icon, name, slug, topic count, article count, guide count, status, last updated.
Editor: Name, Slug, Description, Featured Image, Icon, Accent Color, SEO fields, Featured Toggle, Display Order, Visibility.

## TOPIC LIST/EDITOR
List: name, parent category, description, article/guide/tool counts, status, actions — filterable by category.
Editor: Name, Slug, Parent Category (required — no orphaned topics), Description, Featured Image, SEO fields, Featured Toggle, Display Order, Status.

## DETAILS PAGES
Category Details and Topic Details: overview stats, related content, quick actions — via Content Service (MES-002).

## TAXONOMY RULES
One Category → many Topics. One Topic → many Articles/Guides/AI Tools. Validation: no duplicate names/slugs, no orphaned Topics.

## DATABASE
Models: `Category, Topic, CategoryStatus, TopicStatus, CategoryImage, TopicImage`. This is the shared taxonomy layer MES-008, MES-010, MES-011 all reference through the Content Service — no module re-implements category/topic relationships independently.

---

## WHAT NOT TO BUILD
Homepage integration, public category/topic pages (MES-024–026), Learning Guides/AI Tools management themselves (their own specs), search, analytics.

---

## ACCEPTANCE CRITERIA
✓ Category and Topic management, editors, detail pages, relationships, and validation all exist. Zero build/TS/lint errors.

---

## STOP
Summarize the taxonomy architecture. Explain how Articles, Guides, AI Tools, Search, Navigation, and Homepage will use it. Wait for MES-010.
