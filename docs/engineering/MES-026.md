# Mendanize Engineering Specification (MES-026)
## Public Learning Guide Experience

**Version:** 1.0
**Dependencies:** MES-002, MES-004, MES-010, MES-015, MES-018, MES-019, MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the public Learning Guide experience — structured, step-by-step educational journeys, distinct from Articles, that keep users progressing through lessons while naturally discovering more content.

---

## BUILD
Guide Landing Page, Guide Overview, Lesson Navigation, Section Navigation, Lesson Content, Resource Panel, Continue Learning Panel, Related Learning. Public Website Layout (MES-004).

## GUIDE HEADER / OVERVIEW
Cover, Title, Description, Category, Topic, Difficulty, Duration, Section/Lesson counts, Author. Overview: Learning Objectives, Prerequisites, Skills, Outline, Start Learning button.

## LESSON NAVIGATION & CONTENT
Previous/Next, expandable sections, current-lesson highlight, completion/progress placeholders. Content renders headings, images, code, tables, quotes, interactive callouts via MES-003's components.

## RESOURCE PANEL
Related Articles, related AI Tools, external references/downloads placeholders — via Recommendations Service (MES-018).

## CONTINUE LEARNING
Next lesson, suggested guides/articles/tools (Recommendations Service), continue with Ask Mendanize AI.

## ASK MENDANIZE AI
Tier 1 public widget (MES-019) scoped to the current lesson: "Ask About This Lesson," "Explain This Concept," "Summarize Lesson."

## SEO
Full Appendix A SEO Standard, guide-specific structured data (HowTo/Course schema) via the SEO Service (MES-015).

---

## WHAT NOT TO BUILD
Real progress tracking/completion, certificates, quizzes, assignments, bookmarks, downloads.

---

## ACCEPTANCE CRITERIA
✓ Guide page, overview, lesson navigation, resource panel, continue learning, Ask Mendanize AI integration, SEO all exist. Zero build/TS/lint errors.

---

## STOP
Summarize the architecture. Explain integration with Articles, AI Tools, User Learning, Search, SEO, Ask Mendanize AI. Wait for MES-027.
