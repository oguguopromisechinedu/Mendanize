# Mendanize Engineering Specification (MES-018)
## Recommendations Engine

**Version:** 1.0
**Status:** Foundation Specification — NEW, closes a duplication gap
**Dependencies:** MES-002 (Shared Services & API Architecture), MES-017 (Search)

Follows MSEM Appendix A. No exceptions.

---

## WHY THIS SPEC EXISTS

In the previous sequence, "related content" and "recommended for you" logic was independently invented in Search, Personalization, Analytics, and each public content page (Article, Guide, AI Tool) — four different `Recommendation`-style models with no shared contract. This spec makes it one system.

---

## WHAT IT OWNS

- **Related content** — shown on Article/Guide/AI Tool detail pages (public surfaces): related Articles, Guides, Tools, Categories, Topics for a given piece of content.
- **Recommended for you** — shown on the Personalization dashboard and homepage: content suggestions based on a user's saved items, interests, and history.
- **Search-adjacent suggestions** — "you might also search for," trending topics.

All three are facets of one engine, not three separate features.

---

## PHASE 1 STRATEGY (this spec's actual build)

Rules-based, not ML-based, for this phase:

- **Related content** = shared Category/Topic overlap with the current item, weighted by recency and featured status. Deterministic, explainable, fast.
- **Recommended for you** = union of (a) content in the user's selected interests (My Interests, per Personalization module) and (b) related content of the user's saved/recently-viewed items.
- **Trending** = simple view-count ranking over a rolling window (placeholder data until Analytics' real event tracking lands).

---

## INTERFACE

One function signature every consuming module calls:

`getRecommendations({ contextType: 'article' | 'guide' | 'tool' | 'user' | 'trending', contextId, limit })`

Returns a consistent shape: `{ items: [{ type, id, title, slug, thumbnail, reason }] }` — the `reason` field (e.g. "Because you saved X") is included so calling UI can optionally explain the recommendation.

---

## SCOPE OF THIS PHASE

Build: the rules-based engine described above, the shared interface, and wiring for Article/Guide/Tool detail pages, the Personalization dashboard, and Search to all call it.
Do NOT build yet: ML-based/embedding-based recommendations, real-time personalization, A/B tested ranking — future enhancement once there's usage data to justify it.
