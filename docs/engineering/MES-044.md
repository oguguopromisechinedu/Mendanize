# Mendanize Engineering Specification (MES-044)

## Coding Workspace Execution Engine

**Version:** 1.0 — the security-critical follow-up explicitly deferred by MES-039 (Building Hub stored workspace metadata only).  
**Status:** Complete (MVP) — see [MES-044-COMPLETION.md](../MES-044-COMPLETION.md)  
**Dependencies:** MES-002 (Logging, Audit), MES-006/MES-030, MES-021 (optional tier gating), MES-032, MES-039 (workspace/project models), MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE

Run learner-submitted code in an isolated sandbox with hard resource limits — turning the Coding Workspace from a file editor into a safe execution environment.

---

## THREAT MODEL (non-negotiable)

User code is hostile by default. The engine must prevent:

- Host filesystem escape  
- Network abuse (SSRF to internal services, crypto mining)  
- Unbounded CPU/memory/disk/time  
- Cross-tenant data access  

If a proposed design cannot state how each is mitigated, it is not shippable.

---

## MVP SCOPE

- Languages: start with **one** runtime (recommend JavaScript/TypeScript or Python — pick one and document why).  
- Ephemeral container/sandbox per run; destroy after timeout.  
- stdin/stdout/stderr capture with size caps.  
- Per-`PublicUser` rate limits; stronger limits for free tier (MES-021 entitlements).  
- Workspace files from MES-039 models are the only inputs — no arbitrary URL fetch in v1 unless explicitly allowlisted.

Admin: kill switch + usage view (MES-007). Every run audit-logged.

---

## WHAT NOT TO BUILD

Multi-language IDE parity. GPU / ML training jobs. Persistent VMs. Kubernetes GitOps platforms. “Deploy to production” from learner sandboxes. Browser-based native mobile/AR runtimes.

---

## ACCEPTANCE CRITERIA

✓ Code runs only inside the sandbox. ✓ Resource limits enforced and tested. ✓ Rate limits and kill switch work. ✓ Dual-auth: execution is `PublicUser`-only; Admin ops never require sharing learner sessions. Zero build/TS/lint errors.

---

## STOP

Summarize sandbox vendor/architecture choice and threat mitigations. Do not expand language matrix without a new MES.
