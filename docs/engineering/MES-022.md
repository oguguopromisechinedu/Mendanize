# Mendanize Engineering Specification (MES-022)
## User Learning Experience & Personalization

**Version:** 1.0
**Dependencies:** MES-002, MES-006 (Auth), MES-018 (Recommendations), MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Give every authenticated learner a personalized learning space — dashboard, saved resources, progress, recommendations — turning Mendanize from a content platform into a personalized one.

---

## BUILD
My Learning Dashboard, Continue Learning, Saved Articles/Guides/Tools, Learning History, Recommended For You, My Interests, Account Preferences. Authenticated user layout.

## MY LEARNING DASHBOARD
Welcome, Continue Learning, Learning Statistics, Recently Viewed, Saved Content, Recommended Content (via Recommendations Service, MES-018), Learning Streak/Weekly Goal placeholders.

## CONTINUE LEARNING
Guide progress cards: last lesson, remaining lessons, estimated completion, resume button. Real progress tracking is a future spec — this phase builds the interface against placeholder progress data.

## SAVED CONTENT
Saved Articles/Guides/Tools — search, filter, sort, remove, open.

## LEARNING HISTORY
Recently read/viewed/opened content, search history placeholder, Ask Mendanize AI history placeholder (real history exists once MES-019's Tier 2 is live).

## RECOMMENDED FOR YOU
Calls the Recommendations Service (MES-018) with `contextType: 'user'` — does not reimplement recommendation logic.

## MY INTERESTS
Interest selection from the platform's Category/Topic taxonomy (MES-009) — feeds the Recommendations Service.

## ACCOUNT PREFERENCES
Preferred Difficulty, Learning Goals, Daily Reminder placeholder, Preferred Categories/Topics, Theme (reads from Design Customization, MES-003/MES-020).

## SECURITY
Private learning history and saved resources — per Appendix A Security Baseline, enforced at the data layer, not just hidden UI.

## DATABASE
Models: `UserInterest, SavedArticle, SavedGuide, SavedAITool, LearningHistory, LearningGoal, UserPreference`. `LearningProgress` modeled as placeholder — real tracking depends on Guide lesson completion logic, a future spec.

---

## WHAT NOT TO BUILD
Real recommendation algorithms beyond MES-018's rules-based engine, real progress/streak calculations, email reminders, push notifications, gamification/badges.

---

## ACCEPTANCE CRITERIA
✓ Dashboard, Continue Learning, Saved Content, History, Recommendations, Interests, Preferences all exist. Zero build/TS/lint errors.

---

## STOP
Summarize the architecture. Explain integration with Auth, content modules, Recommendations, and Ask Mendanize AI. Wait for MES-023.
