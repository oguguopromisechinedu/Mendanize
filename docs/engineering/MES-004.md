# Mendanize Engineering Specification (MES-004)
## Public Website Structure & Global Navigation

**Version:** 2.0 (renumbered from original MES-003)
**Dependencies:** MES-002 (Shared Services), MES-003 (Design System), MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the complete public website shell — Home, Categories, Learn, Guides, AI Tools, About, Contact, Search — every future public page inherits this layout.

---

## BUILD
Reusable Public Layout: Global Header, Global Navigation, Main Content Area, Global Footer.

---

## HEADER
Premium sticky header: Logo, Primary Navigation, Search Button, Theme Toggle (UI only), Sign In Button, Mobile Menu Button. Sticky on scroll, uses MES-003 components. Navigation items load from the Settings Service (MES-002) / Navigation Manager (MES-015) — never hardcoded.

## NAVIGATION
Desktop: active links, hover states, keyboard nav, dropdown-ready. Mobile: slide-out drawer, smooth animation, accessible focus handling, close on navigate.

## FOOTER
Global footer arrangement (exact structure — preserve this order and grouping). Content managed via dashboard Navigation Manager (MES-016), not hardcoded.

### Layout
- Mobile: 2-column grid; Brand spans both columns first.
- Desktop (`lg+`): 5 columns — Brand | Explore | Resources | Company | Popular Topics (`1.4fr 1fr 1fr 1fr 1.2fr`).
- Below columns: full-width **Newsletter** row (email + Subscribe).
- Bottom bar: full-width copyright strip under a top border.

### Column 1 — Brand
- Logo mark (`M`) + brand name **Mendanize**
- Tagline: *Your trusted source for AI tools, tutorials, news, and everything about artificial intelligence.*
- Social icons (in order): Twitter/X, LinkedIn, YouTube, RSS

### Column 2 — Explore
Links (in order): Blog, Collections, Guides, Roadmaps, Deals

### Column 3 — Resources
Links (in order): Prompt Library, Newsletter, Free Resources, Glossary, AI Courses

### Column 4 — Company
Links (in order): About Us, Contact, Privacy Policy, Terms of Use, Write for Us  
*(Legal links live inside Company — no separate Legal column.)*

### Column 5 — Popular Topics
Chip/tag list (in order): ChatGPT, Claude, Gemini, Midjourney, AI Agents, Prompt Engineering, OpenAI, Stable Diffusion, LangChain, Llama 2, Fine-tuning, Vector DB

### Newsletter
Footer includes a **Newsletter** block (CMS-managed via MES-016 / homepage newsletter copy via MES-013):
- Headline (placeholder / CMS): e.g. subscribe / stay updated messaging
- Short supporting line
- Email input + Subscribe button
- Privacy note (e.g. *No spam. Unsubscribe anytime.*)
- Placement: below the five-column grid (full-width row under Brand / Explore / Resources / Company / Popular Topics), above the copyright bar — or as an optional sixth column when the Navigation Manager enables it. Default reference placement is the **full-width row under the columns**.

### Copyright bar
`© {year} Mendanize. All rights reserved.`

### Related (not a substitute)
Homepage **Stay Updated** aside beside Latest Articles (MES-005) may reuse the same newsletter wiring; the **global footer Newsletter** remains part of the Public Layout footer.
