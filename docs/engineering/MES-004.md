# Mendanize Engineering Specification (MES-004)
## Public Website Structure & Global Navigation

**Version:** 2.0 (renumbered from original MES-003)
**Dependencies:** MES-002 (Shared Services), MES-003 (Design System), MSEM Appendix A

Follows MSEM Appendix A. No exceptions.

---

## OBJECTIVE
Build the complete public website shell — Home, Categories, Learn, Guides, AI Tools, About, Contact, Search — every future public page inherits this layout.

---

## BUILD
Reusable Public Layout: Global Header, Global Navigation, Main Content Area, Global Footer.

---

## HEADER
Premium sticky header: Logo, Primary Navigation, Search Button, Theme Toggle (UI only), Sign In Button, Mobile Menu Button. Sticky on scroll, uses MES-003 components. Navigation items load from the Settings Service (MES-002) / Navigation Manager (MES-015) — never hardcoded.

## NAVIGATION
Desktop: active links, hover states, keyboard nav, dropdown-ready. Mobile: slide-out drawer, smooth animation, accessible focus handling, close on navigate.

## FOOTER
Sections: Brand, Learning Categories, Resources, Company, Legal, Social Links, Newsletter placeholder. Content managed via dashboard (MES-015), not hardcoded.

---

## PUBLIC ROUTES (placeholders)
`/`, `/learn`, `/guides`, `/categories`, `/ai-tools`, `/about`, `/contact`, `/search` — each uses the Public Layout, clean placeholder title, fully responsive.

## GLOBAL SEARCH
Interface only (Search Modal, Search Input, Recent/Suggested Searches placeholders) — real logic is MES-016.

## BREADCRUMB SYSTEM
Reusable component, auto-supports future pages.

## PAGE CONTAINER
Layout utilities: standard width, wide content, full-width sections, hero containers, section spacing.

---

## WHAT NOT TO BUILD
Homepage sections, Articles, Learning Guides, AI Assistant, Auth Pages, Dashboard Pages, Dynamic Data, Business Logic.

---

## ACCEPTANCE CRITERIA
✓ Public Layout, sticky header, responsive nav, mobile menu, footer, placeholder routes, search UI, breadcrumb, layout utilities all exist and follow MES-003.

---

## STOP
Summarize components, routes, layout architecture, future integration points. Wait for MES-005.
