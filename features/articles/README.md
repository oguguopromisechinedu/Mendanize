# articles

**Implements:** MES-008 (admin CMS), MES-025 (public reading experience)

**Shared Services:** `content`, `media`, `seo`, `ai`, `recommendations`

Admin Article CMS — list, editor, TipTap rich text, SEO panel, preview, workflow states, AI assist entry point.

Public — `/articles`, `/articles/[slug]` reading layout (progress, TOC, Ask Tier 1, related via MES-018, SEO).
